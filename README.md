# ImproMaths for Parents: finished reels

Finished talking-head reels for the ImproMaths for Parents channel (1080x1920, MP4).
Each file is linked from the Video Link column of the Reel Scripts sheet and picked up by the Make posting scenario, which sends it to Blotato.

This repo is public on purpose: Blotato needs a public link to fetch each video. Code, photos and anything private live elsewhere.

Public link format:
`https://raw.githubusercontent.com/ImproAbility/impromaths-reels-parents/main/reels/<file>.mp4`
